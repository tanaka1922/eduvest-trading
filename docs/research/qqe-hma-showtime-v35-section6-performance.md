## 1. 推奨環境

### 1.1 推奨銘柄

QQE v3.5は以下の銘柄で最高のパフォーマンスを発揮します:

#### **🥇 最適銘柄（QQEファクター自動最適化済み）**

| 銘柄 | QQEファクター | スプレッド目安 | 1秒足での動き | 推奨度 |
|------|--------------|--------------|-------------|--------|
| **BTCUSDT.P** | 12.0 | 0.1-0.5 USDT | 大（100-500円/秒） | ⭐⭐⭐⭐⭐ |
| **ETHUSDT.P** | 10.0 | 0.01-0.05 USDT | 中（10-50円/秒） | ⭐⭐⭐⭐⭐ |
| **USDJPY** | 4.238 | 0.2-0.5 pips | 小（1-5 pips/秒） | ⭐⭐⭐⭐ |
| **EURUSD** | 3.8 | 0.5-1.0 pips | 小（1-3 pips/秒） | ⭐⭐⭐ |
| **GOLD (XAUUSD)** | 8.0 | 0.3-0.8 USD | 中（0.5-2 USD/秒） | ⭐⭐⭐⭐ |

**選択基準:**
1. **ボラティリティ**: 1秒で意味のある値動きがある
2. **流動性**: 24時間取引可能、スリッページが少ない
3. **スプレッド**: 狭い（利益を圧迫しない）
4. **取引コスト**: 低い（手数料・スワップ）

---

#### **❌ 非推奨銘柄**

- **株式個別銘柄**: 1秒足が使えない
- **流動性が低いアルトコイン**: スプレッドが広すぎる
- **マイナー通貨ペア**: 動きが不規則、ノイズが多い

## 3. リスク管理の実践

### 3.1 資金管理の鉄則

#### **ルール1: 1回の損失は資金の1-2%以内**

**計算例（資金10万円の場合）:**
```
資金: 100,000円
許容損失: 2%（2,000円）

損切り幅 = ATR × stop_atr_multi
→ 損切り幅が2,000円以内になるようロット調整

例: BTC、ATR=500円、stop_atr_multi=1.0
損切り幅 = 500円
→ ロット0.04まで可能（500円 × 0.04 = 2,000円）
```

> 資金管理の計算式を図解（フローチャート形式）

---

#### **ルール2: 最大ドローダウン20%で運用停止**

```
資金: 100,000円
ドローダウン20%: 80,000円に減少

→ この時点で運用を一時停止
→ 原因分析
→ パラメータ見直し
→ デモで再検証
→ 再開
```

**なぜ20%？**
- 回復可能な範囲
- 心理的な限界
- 統計的に異常値の可能性

---

#### **ルール3: レバレッジは3倍以下**

| レバレッジ | リスク | 推奨対象 |
|-----------|--------|---------|
| **1倍** | 最低 | 超保守的・初心者 |
| **3倍** | 低 | 初心者・中級者（推奨） |
| **5倍** | 中 | 中級者・上級者 |
| **10倍** | 高 | 上級者のみ |
| **20倍+** | 極大 | 非推奨 |

**なぜ3倍？**
- ロスカットまでの余裕がある
- 連敗しても耐えられる
- 精神的に安定

### 3.2 損切りの徹底

#### **損切りの重要性**

**損切りなし = 破産確定**

```
悪い例:
- エントリー: 96,000円（買い）
- 損切りなし
- 価格下落: 95,000円 → 94,000円 → 93,000円...
- 結果: -3,000円の大損失

良い例:
- エントリー: 96,000円（買い）
- 損切り: 95,500円（-500円）
- 価格下落: 95,500円で自動決済
- 結果: -500円で済む（損失限定）
```

---

#### **損切りのルール**

1. **エントリー前に損切り位置を決める**
   - ATR倍率で自動計算（QQE v3.5の機能）
   - 絶対に変更しない

2. **損切りは必ず設定**
   - 「様子を見る」は厳禁
   - システムに任せる

3. **損切り後は冷静に**
   - 1回の負けは想定内
   - すぐに取り返そうとしない
   - 次のシグナルを待つ

### 3.3 利確の戦略

#### **戦略1: ATR倍率（固定）**

```pine
target_atr_multi = 1.0  // デフォルト

```

```
価格が96,300円に到達
```

**メリット:**

- QQE v3.5では手動（将来自動化予定）

**メリット:**
- リスクを早めに減らせる

### 3.4 日次リセットの重要性

#### **なぜ日次リセット？**

1. **感情のリセット**
   - 前日の勝敗を引きずらない
   - フラットな気持ちで開始

2. **統計的な区切り**
   - 日次の成績を記録
   - 改善点を分析

3. **資金管理の見直し**
   - 1日の損益を確認
   - 翌日のロット調整

#### **リセット時刻の設定**

```pine
reset_hour = 6  // 午前6時（JST）
```

**推奨時刻:**
- 午前6時: 早朝の閑散時間帯
- 市場への影響が少ない
- 日本時間に合わせやすい

## 4. バックテストの手順

### 4.1 TradingViewでのバックテスト

#### **Step 1: Pine Scriptの貼り付け**

1. TradingViewを開く
2. チャート右上の「Pine エディタ」をクリック
3. QQE v3.5のコードを貼り付け
4. 「保存」→「チャートに追加」

---

#### **Step 2: 銘柄・時間足の設定**

1. 銘柄を選択（例: BTCUSDT.P）
2. 時間足を「1s」（1秒）に変更
3. タイムゾーンを「GMT+9」（JST）に設定

---

#### **Step 3: ストラテジーテスター起動**

**※ 注意:**
QQE v3.5は「indicator」なので、標準のストラテジーテスターは使えません。

**代替方法:**
1. **手動でシグナルを確認**
   - ラベルが表示された箇所をメモ
   - 損益を記録

2. **Pine Scriptをstrategy版に改造**
   - `indicator()` → `strategy()`
   - エントリー・イグジットを `strategy.entry()` / `strategy.close()` に変更

3. **リプレイモード**
   - TradingView Pro+以上
   - 過去チャートを再生しながら検証

**📊 画像が欲しい箇所⑥:**
> TradingViewのリプレイモード画面（バックテスト中）

---

#### **Step 4: パラメータ最適化**

**最適化する項目:**
- QQEファクター（銘柄により調整）
- HMA期間（7-12で試す）
- AIスコア閾値（50-70で試す）
- ATR倍率（0.8-1.5で試す）

**最適化の手順:**
1. 1つのパラメータだけ変更
2. 30日間のバックテスト
3. 勝率・PFを記録
4. 最も良い値を採用
5. 次のパラメータへ

**⚠️ 注意:**
- 過剰最適化（オーバーフィッティング）を避ける
- 複数の期間で検証（2024年9月、10月、11月等）
- フォワードテスト（未来のデータ）で確認

### 4.2 記録すべき指標

#### **基本指標**

| 指標 | 意味 | 目標値 |
|------|------|--------|
| **総トレード数** | エントリー回数 | 500回以上（統計的信頼性） |
| **勝率** | 勝ちトレード / 総トレード | 55%以上 |
| **プロフィットファクター (PF)** | 総利益 / 総損失 | 1.5以上 |
| **最大ドローダウン** | 最大の資金減少率 | 20%以内 |
| **平均勝ち額** | 勝ちトレードの平均 | - |
| **平均負け額** | 負けトレードの平均 | - |

**プロフィットファクター (PF) の計算:**
```
総利益: 100,000円
総損失: 60,000円
PF = 100,000 / 60,000 = 1.67（良好）

PF 1.5以上 = 優秀
PF 1.2-1.5 = 合格
PF 1.0-1.2 = 改善必要
PF 1.0未満 = 使えない
```

---

#### **詳細指標**

| 指標 | 意味 | 備考 |
|------|------|------|
| **最大連勝** | 何回連続で勝ったか | 精神的な支え |
| **最大連敗** | 何回連続で負けたか | リスク管理の目安 |
| **平均保有時間** | 1トレードの平均時間 | 1秒足なら10-60秒 |
| **シャープレシオ** | リスク調整後リターン | 1.0以上が理想 |
| **リカバリーファクター** | 純利益 / 最大DD | 2.0以上が理想 |

**原因:**

```
3. 銘柄をBTCUSDT.Pに変更
4. 時間足を1秒に変更

```

#### **問題2: バックテストと実運用の成績が違う**

**原因:**
- スリッページ（約定遅延）
- スプレッドの変動
- 流動性の違い
- 心理的な要因（手動介入）

**解決策:**
```
1. スリッページを考慮（±0.5-1.0 USDT）
2. スプレッドが広い時間帯を避ける
3. 完全自動化（API連携）
4. デモで再検証
```

---

#### **問題3: 連敗が続く**

**原因:**
- レンジ相場が続いている
- ボラティリティが低い
- パラメータが合っていない

**解決策:**
```
1. 相場環境を確認（レンジ？トレンド?）
2. AIスコア閾値を上げる（50→60）
3. 時間帯を変える（NY時間等）
4. 一時的に運用停止→分析
```

---

#### **問題4: 利益が伸びない**

**原因:**
- 利確が早すぎる
- トレンドに乗れていない
- 勝率は高いが利幅が小さい

**解決策:**
```
1. target_atr_multi を大きく（1.0→1.5）
2. トレーリングストップ導入
3. ULTRAシグナルのみに絞る
```
