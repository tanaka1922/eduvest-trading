# Lorentzian Classificationインジケーター完全攻略ガイド

Justin Dehorty氏が開発したLorentzian Classification（ローレンツ分類）は、**k近傍法（k-NN）にローレンツ距離メトリックを適用した機械学習ベースのテクニカル指標**である。TradingViewで14,000以上のブースト数を獲得し、トップ50の人気指標にランクインしている。この指標の最大の特徴は、重要な市場イベント時に発生する「価格-時間のワープ」を考慮できる点にあり、従来のユークリッド距離ベースの手法よりも**外れ値に対して頑健**である。学術研究により、時系列データの分類精度でマンハッタン距離、コサイン類似度、バッタチャリヤ距離を上回ることが実証されている。

本レポートでは、Lorentzian Classificationと他のテクニカル指標を組み合わせた最適なトレード戦略を、トレードスタイル別、経験レベル別、市場別に徹底解説する。勝率60%以上を目指す初心者向けシステムから、プロフィットファクター2.0以上を狙う中級者向けシステム、さらにFX特化の実践的設定まで、実際のバックテスト結果とPine Scriptコード例を含めて包括的に提示する。

## スイングトレード向け最適組み合わせ

Lorentzian Classificationは**4時間足から日足のスイングトレードで最も高いパフォーマンス**を発揮する。これは、長い時間軸では各ローソク足に含まれる出来高が多く、ノイズが少ないためである。

### トレンドフォロー系との最強組み合わせ

最も実績のある組み合わせは**Lorentzian + 200EMA + Supertrend + ATR**である。この4指標システムは米国500指数の1時間足で2022年から2023年にかけて検証され、実際のスプレッド（往復0.06%）を考慮した上で正のリターンを記録した。エントリールールは明確だ。ロングポジションでは価格が200EMAの上にあり、Lorentzianが買いシグナルを出し、Supertrendが強気を示すときのみエントリーする。ショートはその逆となる。

ストップロスはATRの2倍の距離に設定し、1対1のリスクリワード比でブレークイーブンに移動、3対1で50%を利確し、残りは反対シグナルまたはSupertrend転換で決済する。この戦略は**負けトレードの方が多いが、勝ちトレードの規模が大幅に大きい**のが特徴で、例えば最大勝ちトレードが438ドルに対し最大損失が101ドルという結果が記録されている。

より高度なアプローチとして**Pivot Boss 4EMAシステム**がある。21EMA（トリガーライン）、45EMA、90EMA、200EMAを使用し、21EMAが45と90の両方を上抜け、かつ全てのEMAがトリガーライン以下にあり、価格が200EMA以上でLorentzianが買いシグナルを出したときにエントリーする。このセットアップは複数時間軸の整合性を要求するため、偽シグナルが劇的に減少する。ストップロスは直近のスイング安値（ロング）またはスイング高値（ショート）に設定し、ターゲットはストップロスの1.2倍から1.7倍の距離とする。

### ボリューム系指標との組み合わせ

VWAPとの組み合わせは特に効果的である。VWAPは機関投資家が注目する均衡価格を示すため、**Lorentzianの買いシグナルが価格がVWAPの上から跳ね返るタイミングで出た場合**、高確率のロングエントリーとなる。この組み合わせは、もみ合い相場での偽シグナルを効果的にフィルタリングする。

OBV（オンバランスボリューム）を追加すると、出来高による確認が可能になる。出来高は価格に先行する傾向があるため、OBVが上昇トレンドを示している時のLorentzian買いシグナルは信頼性が高い。ダイバージェンス（価格が新高値を更新したがOBVが更新していない）は重要な反転サインとなる。

Volume Profileを使用する場合、高出来高ノード（HVN）やポイント・オブ・コントロール（POC）でのLorentzianシグナルに注目する。これらのレベルは強力なサポート・レジスタンスとして機能するため、シグナルの信頼性が向上する。

### 推奨保有期間と時間軸設定

スイングトレードでは日足チャートが最も信頼性が高い。1日1本のローソク足で分析が管理しやすく、24時間分の出来高を含むためシグナルの質が高い。典型的な保有期間は2日から10日である。4時間足は副次的な時間軸として使用でき、保有期間は1日から5日となる。マルチタイムフレーム分析では、週足で全体トレンドを確認し、日足でエントリーセットアップを探し、4時間足でエントリータイミングを微調整するアプローチが推奨される。

## デイトレード向け最適組み合わせ

デイトレードでは**15分足が最適なバランス**を提供する。1時間に4本のローソク足が形成されるため手動トレードでも管理可能であり、1分から5分足のノイズの大部分をフィルタリングできる。

### モメンタム系指標との三重確認戦略

最も効果的なデイトレード戦略は**Lorentzian + MACD + RSI**の組み合わせである。エントリーには3つの条件全てが1〜2本のローソク足以内に揃う必要がある。ロングの場合、MACDラインがシグナルラインを上抜け、RSIが30以上70未満（まだ買われ過ぎではなく上昇余地がある）、そしてLorentzianが買いシグナルを出す。

設定は標準的なもので機能する。MACDは12、26、9、RSIは14期間（より速い反応が必要な場合は9〜11期間）、Lorentzianは8近傍でボラティリティフィルターを有効化する。イグジットはMACDのモメンタム転換（ヒストグラムの縮小）またはRSIが極端レベル（80以上または20以下）に達した時点で行う。ストップロスはATRの1.5倍から2倍に設定する。この三重確認システムは**バックテストで73%の勝率**を記録している。

Stochastic Oscillatorとの組み合わせは、レンジ相場や反転トレードに適している。ストキャスティクスの%Kが%Dを上抜け、かつ20以下の売られ過ぎゾーンにあり、Lorentzianが買いシグナルを出してストキャスティクスが売られ過ぎゾーンを抜ける時点でエントリーする。

### プライスアクションとの統合

ピボットポイントとの組み合わせは客観的なサポート・レジスタンスレベルを提供する。日次ピボットポイント、S1/S2、R1/R2を計算し、価格がこれらのレベルに接近したときにLorentzianシグナルを待つ。レベルからの反発とLorentzianシグナルが重なると高確率トレードとなる。ストップロスはピボットレベルのすぐ外側（5〜10pips）に設定し、タイトなストップを維持できる。

ブレイクアウトトレードでは、価格がレジスタンスを上抜け（またはサポートを下抜け）、出来高が20期間平均を上回り、Lorentzianがブレイクアウト方向のシグナルを出すことを確認する。偽ブレイクアウトを避けるため、2〜3本のローソク足がレベルを超えてクローズすることと、出来高の確認、強いLorentzianシグナル（高い近傍数の合意）を待つ。

### 時間帯フィルターによる精度向上

時間帯はシグナル品質に**大きな影響**を与える。為替市場では、ロンドンセッション（EST午前3時〜12時）がEUR、GBP通貨ペアで最高の出来高を提供する。ニューヨークセッション（EST午前8時〜午後5時）は全てのUSDペアに最適で、ロンドンとの重複時間（EST午前8時〜12時）が最高のボラティリティとなる。

株式市場では**午前10時から午後3時（EST）が最適なトレード時間帯**である。これは機関投資家が最も活発に取引する時間帯で、最高の出来高によりLorentzianシグナルの信頼性が最大化される。市場オープン直後の30分から1時間は初期ボラティリティが落ち着くまで観察のみとし、午後3時以降の最終時間は避けるべきである（クロージングモメンタムを特に狙う場合を除く）。

主要な経済指標発表（FOMC、雇用統計、CPI等）の30分前から1時間後はトレードを避ける。1分足チャートでMESのRTHセッション中にトレードする場合、スコアが5未満のシグナルをフィルタリングする必要がある。

## スキャルピング向け組み合わせ

スキャルピングは**最も難易度が高く、ほとんどの個人トレーダーが失敗する**トレードスタイルである。5分足スキャルピング戦略の実証例として、Lorentzian Classification + Slow MACD（32、64、12）がある。買いはLorentzianの買いアロー + MACD > 0、売りはLorentzianの売りアロー + MACD < 0でエントリーし、ストップロスは直近のスイング高値/安値、利益目標は最低1.1対1.5の比率または トレーリングストップを使用する。

この戦略はGBPJPY、BTCUSD、原油、テスラ、VIX、EURAUD、AUDUSD、AUDJPY、EURJPY、NZDUSD、GBPUSDでテストされており、ライブトレード前に**63%以上の勝率を達成することが推奨**される。

### 代替チャートタイプの活用

Range Barは、指定された価格レンジが蓄積された後に新しいバーが形成される。例えば10pipsごとに新しいバーが形成される。これはノイズをフィルタリングし、純粋な価格動きに焦点を当てるため、トレンドフォローに効果的である。ただし、MT4/MT5ではサードパーティプラグインが必要で、カスタムFXTファイル生成が必要な場合がある。

Renkoチャートは、価格が一方向にのみ動いた後にブリックが形成される点でRange Barと異なる。ATRベースのブリックサイズ（自動的にボラティリティに調整）が推奨される。Renkoは市場ノイズを切り抜け、クリーンなトレンドシグナルを識別するのに優れているが、未完成の間隔中のプロジェクションバーが誤解を招く可能性があり、合成価格の性質上バックテストには推奨されない。

実用的な推奨として、代替チャートタイプを実験する前に、まず標準的な時間ベースのチャート（1分、5分）で開始すべきである。Lorentzianのパフォーマンスは時間ベースデータで十分に文書化されている。

### オーダーフローとDOM分析の統合

オーダーフローは、各価格レベルでの買い・売り出来高、トレードの攻撃性、出来高デルタなどの重要データを提供する。フットプリントチャートはローソク足内の各価格レベルでの買い手対売り手の不均衡を示す。Lorentzianシグナルを方向性バイアスに使用し、オーダーフローをエントリータイミングに使用する組み合わせアプローチが効果的である。

例えば、Lorentzianが強気シグナルを示した場合、フットプリントチャートで買い圧力を確認し、サポートレベルで攻撃的な買い手が優勢になった時点でエントリーする。大口注文の検出には「大口追跡」ツールを使用し、機関投資家の活動を識別する。

実用的なツールとして、ATAS Platform（月額€19.95〜€49.95）がSmart DOM、Smart Tape、Footprintインジケーターに特化している。Bookmapは流動性のヒートマップ可視化、DOM表面、氷山検出を提供する。ただし、**オーダーフローにはリアルタイムのレベル2データフィードが必要**で、ヒストリカルなオーダーフローデータはほとんど利用できない。

### 高頻度取引に関する重要な警告

真の高頻度取引（HFT）は個人トレーダーには実現不可能である。HFTはマイクロ秒（0.000001秒）単位で動作するのに対し、個人の執行速度は最低でもミリ秒（0.001秒）単位である。インフラコストは月額5,000〜50,000ドルのプレミアムデータフィード、2万ドル以上の高性能サーバー、月額8,000ドルのコロケーションサービス、最大100万ドルのカスタムソフトウェア、年間基本給15万ドル以上の専門人材を含む。

Lorentzian Classificationは高頻度取引ではなく、**1分から1時間の時間軸に最適**である。計算オーバーヘッドを減らすため4バーごとの計算が推奨される。HFTは株式出来高の10〜40%、FX/商品の10〜15%を占め、平均保有時間は株式で22秒である。個人トレーダーはレイテンシーで競争できないため、戦略の質で競争しなければならない。

## マルチタイムフレーム分析の実践

階層的フレームワークでは、上位時間軸（日足、4時間足、1時間足）で主要トレンド方向と主要サポート・レジスタンスを識別し、下位時間軸（5分、15分、30分）で上位時間軸トレンド内での正確なエントリー・イグジットタイミングを図る。

上位時間軸の設定では、より長いルックバックウィンドウ（Max Bars Backを5000以上に増やす）を使用し、レジームフィルターを有効化してトレンド相場とレンジ相場を確認し、主要な買い/売りアローに焦点を当ててマイナーなシグナルを無視する。下位時間軸では標準設定（Max Bars Back: 2000）を使用し、全てのフィルター（ボラティリティ、レジーム、ADX）を有効化し、トレンド継続エントリーのためプルバック三角形を活用する。

### プレミアム機能によるMTF強化

Daily Kernel Trend Filter（LC Premium機能）は、下位時間軸チャートに上位時間軸トレンドをオーバーレイし、**逆張りシグナルを最大60%削減**する。日足以上の時間軸では自動的に無効化される。これは1分から15分足を使用するイントラデイトレーダーにとって必須の機能である。

First Pullback Detection Systemは、緑/赤の三角形シグナルでトレンド継続エントリーを提供する。これはメイン分類アローの前に発火し、初期モメンタム移動後の最適なエントリーゾーンを識別する。

### パラメータ最適化の時間軸別ガイド

1分足ではRSI期間7〜9、近傍数5〜8、Max Bars Back 1000〜2000が適切である。5分足ではRSI 14、近傍数8、Max Bars Back 2000〜3000。15分足ではRSI 14〜21、近傍数8〜12、Max Bars Back 3000〜5000。1時間足ではRSI 21〜28、近傍数12〜16、Max Bars Back 5000以上。日足ではRSI 28〜35、近傍数16〜20、Max Bars Back 10000以上となる。

コミュニティ研究からのグリッドサーチテストにより、数千のパラメータ組み合わせにわたって、最適な近傍数は市場レジームによって大きく異なり、安定領域は時間軸によって異なることが判明している。

### MTF確認戦略

三重時間軸確認では、週足/日足でマクロトレンド方向を確立し、4時間/1時間でスイング構造と中間トレンドを識別し、15分/5分でLorentzianシグナルによる正確なエントリーを特定する。最低限として3つのうち2つの時間軸が整合している必要があり、最適には全3時間軸が一貫したLorentzian方向を示し、出来高プロファイルとオーダーフローが方向を確認する。

## リスク管理との統合

動的ストップロスの実装は、Lorentzian Classificationの成功に不可欠である。ATRベースのストップロス公式は、ストップロス距離 = 現在のATR × 乗数となる。通常のボラティリティでは2倍ATR、高ボラティリティでは2.5〜3倍ATR、ブレイクアウトトレードでは3倍以上のATR、スキャルピングでは1.5〜2倍のATRを使用する。

Lorentzianとの実装では、Lorentzianが買い/売りシグナルを生成した時点でエントリーし、初期ストップをエントリー価格±（ATR × 2）に設定する。Lorentzian信頼度が高い場合（スコア7〜8）、2.5倍の乗数を使用する。次の反対Lorentzianシグナルが現れた時点でイグジット更新する。

### シャンデリアイグジット手法

ロングトレードでは、ストップ = エントリー以降の最高値 - （ATR × 乗数）、ショートトレードではストップ = エントリー以降の最安値 + （ATR × 乗数）となる。これは自動的に利益をトレールしながらボラティリティの余地を許容する。

時間ベースのATR調整として、欧州-米国重複時間（EST午前8時〜12時）は2.5〜3倍の乗数を使用し、アジアセッション（EST午後7時〜午前4時）は1.5〜2倍の乗数を使用し、主要ニュースイベント時は乗数を一時的に50〜100%増加させる。

### ボリンジャーバンドとの組み合わせ

ボリンジャーバンドストップロス戦略では、ロングポジションではストップを下部ボリンジャーバンドの下に配置し、ショートポジションではストップを上部ボリンジャーバンドの上に配置する。利益が発展するにつれてストップを中央バンドに移動させるトレーリング手法を使用する。

Technical Analysis of Stocks & Commoditiesの研究によると、**ボリンジャーバンド + ATRの組み合わせはATR単独と比較してトレードエントリー精度を23%改善**した。ただし、ストップハンティングを避けるため、ボリンジャーバンドのラインにぴったりストップを置かず、バッファ（0.5〜1倍のATR）を追加する。

### ポジションサイジングの自動化

パーセンテージリスク法は、ポジションサイズ = （口座残高 × リスク%）/ ストップロス距離という公式で表される。例えば、口座5万ドル、トレード当たりリスク2%、ストップロス50pips（0.0050）の場合、ポジションサイズ = （50,000ドル × 0.02）/ 0.0050ドル = 1,000ドル / 0.0050ドル = 20万通貨（2ロット）となる。

Lorentzian信頼度ベースのサイジングでは、スコア5〜6で0.5〜1%のリスク、スコア7で1〜1.5%のリスク、スコア8で1.5〜2%のリスク（最大）を使用する。信頼度に関わらず、トレード当たり2%以上のリスクを決して超えてはならない。

### ケリー基準の応用

ケリー公式は、ケリー% = 勝率 - [(1 - 勝率) / リスクリワード比]となる。例えば勝率60%（0.60）、リスクリワード1対2（2.0）の場合、ケリー% = 0.60 - [(1 - 0.60) / 2.0] = 0.60 - 0.20 = 0.40 = 40%となる。

Lorentzianとの実用的応用では、まずLorentzian戦略をバックテストして実際の勝率と平均リスクリワードを決定し、上記の公式を使用してケリー%を計算し、フラクショナルケリー（提案の25〜50%）を適用し（より安全）、Lorentzian予測スコアによって統合する。

**重要な警告：フルケリーは決して使用しない**。過度に攻撃的で大きなドローダウンにつながる。クォーターケリーまたはハーフケリーを使用し、最適成長の50〜75%を捕捉しながらボラティリティを大幅に低減する。ケリーには正確な入力が必要で、勝率を過大評価すると過剰な賭けと破滅につながる。固定パーセンテージリスクをマスターしてから使用すべきである。

## 初心者向けシンプル3指標システム

勝率60%以上を目指す保守的な設定は、**Lorentzian Classification（デフォルト）+ 200EMA（トレンドフィルター）+ RSI(14)（モメンタム）**の組み合わせである。エントリールールは明確で、ロングはLorentzian買い + 価格 > EMA200 + RSI > 50、ショートはLorentzian売り + 価格 < EMA200 + RSI < 50となる。

このシステムのパフォーマンスターゲットは、勝率55〜65%、プロフィットファクター1.5〜1.8、最大ドローダウン15〜20%、最適時間軸は1時間足と4時間足である。

### 設定と管理

Lorentzianのコア設定は、近傍数8（デフォルト）で1〜100の範囲で調整可能、Max Bars Back 2000（十分な履歴データを提供）、5つのフィーチャー（RSI、WT、CCI、ADX、RSI）、ソースはhlc3となる。有効化すべき重要なフィルターは、ボラティリティフィルター（もみ合い相場でのウィップソーを削減）とレジームフィルター（トレンド転換時のエントリーを保証）で、レジーム閾値は-0.1（デフォルト）となる。

リスク管理として、トレード当たり2.5%の資金をリスクにさらす。ポジションサイジング公式は（口座 × リスク%）/ （エントリー - ストップロス距離）となる。1対1のリスクリワード比でブレークイーブンに移動し、3対1で50%を利確し、残りは反対シグナルまたはトレーリングストップまで保有する。

### バックテストとアラート設定

TradingViewでバックテストセットアップを行う場合、必要に応じて別のBacktest Adapterスクリプトを使用し、現実的な手数料（0.03%が一般的）を設定し、スリッページを考慮し、最低6〜12ヶ月のデータでテストし、過去データへの過剰適合を避ける。

アラート設定は自動化に不可欠である。Pine Scriptコード例として、alertcondition(startLongTrade, title='Open Long ▲', message='LDC Open Long ▲ | {{ticker}}@{{close}} | ({{interval}})')を使用する。ウェブフック経由での自動化では、シンボル、サイド（buy/sell）、オーダータイプ（market）、ポジションパーセント、ラベルを含むJSON形式のメッセージを送信する。

## 中級者向け高度な5-7指標システム

プロフィットファクター2.0以上を目指す設定は、シンプルシステムの全フィルターに加えて、Pivot Boss 4EMAシステム（21、45、90、200）、Supertrendインジケーター、ATR動的ストップ、カーネル回帰、出来高分析、プルバック検出を組み合わせる。

エントリーには全ての条件が揃う必要がある。Lorentzianシグナル（ロングで+6から+8）、価格 > 200EMA、21EMAが45と90のEMAをクロス、Supertrendが強気、カーネル回帰が強気という条件である。

このシステムのパフォーマンスターゲットは、勝率45〜55%（トレンドフォロー特性）、プロフィットファクター2.0〜2.5以上、最大ドローダウン20〜25%、リスクリワード比2.5対1から3対1となる。最適市場は、BTCUSD 4時間/日足（5つ星）、ETHUSD 4時間/日足（5つ星）、US500 1時間足（5つ星）、BANKNIFTY 4時間/15分足（5つ星）である。

### 市場レジーム検出の自動化

利用可能なフィルターには、ボラティリティフィルター（もみ合い相場でのウィップソーを削減）、レジームフィルター（トレンド対レンジを検出、-0.1の閾値）、ADXフィルター（トレンド強度を確認、20の閾値）がある。

保守的アプローチでは全てのフィルターをオンにし、ADX閾値を25〜30、レジーム閾値を-0.1から0.1に設定する。攻撃的アプローチではボラティリティフィルターのみ使用し、閾値を下げ、選択的なEMA/SMAフィルターを使用する。

自動化の実装として、Python移植版（pip install advanced-ta）、OctoBot統合、Freqtrade実装、3CommasやCryptoFusion用のウェブフックサポートが利用可能である。

## FX特化：USD/JPYとEUR/USDの最適化

為替市場におけるLorentzian Classificationの優位性は、重要イベント駆動のボラティリティ、外れ値への感受性、価格-時間のワープという為替市場固有の課題に対処できる点にある。

### USD/JPY特化設定

USD/JPYの特性として、スプレッドは0.1〜0.3pips（アクティブ時間帯で主要通貨ペア中最もタイト）、ボラティリティは中程度でGBP/USDよりも低く、最もボラティリティが高い曜日は月曜日（平均149pipsまたは1.08%）、最も低い曜日は水曜日（59pipsまたは0.43%）、最もボラティリティが高い月は3月（570pipsまたは5.28%）で日本の会計年度末のフローが影響する。

Lorentzian設定として、主要時間軸は4時間足（シグナル品質とトレード頻度の最良バランス）、副次的時間軸は日足（高精度、少ないトレード）、スキャルピングは東京セッションとロンドン重複時の15分足が適切である。パラメータ調整では、近傍数10〜12（中程度のボラティリティでより多くの履歴参照が必要）、Max Bars Back 2500〜3000（季節パターンを捕捉）、フィーチャーウェイトはRSIとADXを強調（トレンド挙動が一般的）、ボラティリティフィルターは有効化必須（日銀発表時に重要）、レジームフィルター閾値は-0.05（レンジバウンドなアジアセッション用にわずかにタイト）となる。

### セッション別戦略：USD/JPY

アジアセッション（UTC 23:00〜08:00）では、ブレイクアウトをフェードする戦略（アジアセッションスキャルピング）を採用する。Lorentzian設定は近傍数を15に増やし、タイトなレジーム閾値を使用し、Lorentzianシグナル + マスターキャンドル境界での価格反発でエントリーし、リスクリワードは最低1対1、スプレッド考慮として東京オープン中（UTC 00:00〜03:00）の最もタイトなスプレッド時のみトレードする。

ロンドン/NY重複（UTC 12:00〜16:00）では、モメンタムブレイクアウト戦略を使用する。Lorentzian設定は標準設定、ADXフィルター有効化（>20）、エントリーはLorentzian買いシグナル + 価格がアジアセッションレンジをブレイク + サポートのリテストで、リスクリワードは2対1以上（大きな変動が可能）、ニュースフィルターとして米国雇用統計、Fed決定、日銀発表の30分前/後は避ける。

NYセッション（UTC 12:00〜21:00）では、ボリンジャーバンドとのトレンドフォロー戦略を実行する。Lorentzian設定はルックバックを3000バーに増やし、エントリーはLorentzianシグナル + BBの外側に2連続クローズで、リスクリワードは1.5対1、UTC 19:00以降は日中フローのためポジションサイズを削減する。

### EUR/USD特化設定

EUR/USDの特性として、スプレッドは0.1〜1.0pip（全ペア中最低）、ボラティリティは一般的な低レンジが50〜70pips/日（最近の状況）、最もボラティリティが高い時間帯はUTC 07:00〜16:00（ロンドン/NY重複）、最も低いボラティリティはアジアセッション（最も静かなメジャー）、平均日次レンジは63pips（10週平均）である。

Lorentzian設定として、主要時間軸は日足（優れた流動性による最高精度）、副次的時間軸は4時間足（スイングトレードに適）、イントラデイは15分足でロンドンオープン中（UTC 07:00〜09:00）が最適である。パラメータ調整では、近傍数8〜10（高い流動性 = 信頼できるパターン）、Max Bars Back 2000〜2500（JPYペアより季節性が少ない）、フィーチャーウェイトはRSI、WT、CCIを均等にバランス、ボラティリティフィルターは有効化、レジームフィルター閾値は-0.1（デフォルト最適）となる。

### セッション別戦略：EUR/USD

ロンドンセッション（UTC 07:00〜16:00）では、モメンタムを伴うロンドンブレイクアウト戦略を採用する。Lorentzian設定は標準設定でUTC 07:00〜09:00の時間帯に焦点を当てる。エントリー要件は、Lorentzianの買い/売りシグナルが出現、価格がアジアレンジをブレイク、ブレイクされたレベルのリテスト、EMA確認（21EMAがシグナル方向に45/90EMAをクロス）となる。ストップロスはアジアレンジの反対側、利益確定はアジアレンジサイズ（最低）でトレーリングストップで大きな動きを狙い、スプレッドチェックとしてエントリー時に0.5pips未満であるべきである。

ロンドン/NY重複（UTC 12:00〜16:00）では、高確率トレンド継続戦略を実行する。Lorentzian設定は全フィルター有効化、近傍数 = 10、エントリーはLorentzianシグナル + 価格が200EMAの上/下 + 21EMAトリガーラインクロスで、リスクリワードは1.2対1から1.7対1、出来高確認として出来高が20日平均を超える場合のみトレードする。

### スプレッドとスリッページの実践的考慮

実世界のスプレッドコストは、EUR/USDで平均0.1〜1.0pip（0.5pips = スタンダードロットあたり5ドル）、USD/JPYで平均0.1〜0.3pip（0.2pips = 110.00で約1.80ドル/スタンダードロット）である。15分スキャルピング戦略では、スプレッドが目標利益の20〜40%を消費する可能性がある。

最適化戦略として、ピーク流動性時間帯のみトレード（EUR/USDはロンドンセッション、特にUTC 07:00〜09:00、USD/JPYは東京オープン + ロンドン/NY重複）、ECN/STブローカーを使用して生スプレッド + 手数料モデルを採用、ポジションサイジングにスプレッドを織り込む（例：20pipsターゲットで0.5pipsスプレッド = 実効19.5pipsゲイン）。

スリッページの緩和として、指値注文を使用してLorentzianシグナル価格で指値注文を置く（スリッページゼロだが約定しないリスク）、高流動性期間中のみ執行（EUR/USDはロンドンセッション、ロンドン/NY重複、USD/JPYは東京オープン、NYセッション）、経済カレンダーフィルターを統合して重要ニュースの30分前にLorentzianシグナルを一時停止し30分後に再開、ブローカー執行速度として主要取引センター（ロンドン、ニューヨーク、東京）にVPSコロケーション、平均執行<50ms、リクオートなしのブローカーを選択する。

## Pine Script実装コード例

### オリジナルコード構造

公式ソースはhttps://www.tradingview.com/script/WhBzgfDu-Machine-Learning-Lorentzian-Classification/ で、Mozilla Public License 2.0の下で公開されている。完全なコードはhttps://gist.github.com/itsXactlY/450618a1ab3a85b450b22c8e188c7a1dで入手可能である。

コアアルゴリズムのローレンツ距離計算は、get_lorentzian_distance関数で実装されている。5つのフィーチャーの場合、math.log(1+math.abs(featureSeries.f1 - array.get(featureArrays.f1, i))) + math.log(1+math.abs(featureSeries.f2 - array.get(featureArrays.f2, i))) ... という形式で各フィーチャー間の対数スケールの距離を計算する。

デフォルト設定は、ソースhlc3、近傍数8、Max Bars Back 2000、フィーチャーとしてRSI(14,2)、WT(10,11)、CCI(20,2)、ADX(20,2)、RSI(9,2)で、4時間から12時間足に最適化されている。

### 初心者向けシンプルバージョン

シンプルな3指標システム（60%以上の勝率目標）のPine Scriptコード例：

```pinescript
//@version=5
strategy("Lorentzian Simple Strategy", overlay=true)

// Indicators
ema200 = ta.ema(close, 200)
rsi14 = ta.rsi(close, 14)

// Entry Logic (combine with Lorentzian signals)
longCondition = close > ema200 and rsi14 > 50
shortCondition = close < ema200 and rsi14 < 50

// Risk Management
atrValue = ta.atr(14)
if (longCondition)
    strategy.entry("Long", strategy.long)
    strategy.exit("Exit", stop=close - atrValue*2, limit=close + atrValue*3)
```

このコードは、Lorentzianシグナルと組み合わせて使用するための基本的なトレンドフィルターとモメンタム確認を提供する。

パフォーマンス比較表：トレンド検出でLorentzianは4つ星、移動平均は5つ星、RSI/MACDは3つ星。ノイズフィルタリングでLorentzianは5つ星、移動平均は3つ星、RSI/MACDは2つ星。イベント処理でLorentzianは5つ星、移動平均は2つ星、RSI/MACDは2つ星。使いやすさでLorentzianは4つ星、移動平均は5つ星、RSI/MACDは5つ星となる。

## 最適化の実践的推奨事項

### フィーチャーエンジニアリング

最適化プロセスは、3〜4つのフィーチャーから開始し、フィーチャーを段階的に追加（5〜8以降は収穫逓減）、異なる組み合わせをテスト、組み込み統計をフィードバックに使用し、ワーストケース推定でバックテストするという流れである。

デフォルトフィーチャー（良いスタート）は、F1: RSI(14, 2)、F2: WT(10, 11)、F3: CCI(20, 2)、F4: ADX(20, 2)、F5: RSI(9, 2)となる。

### フィルター設定の最適化

保守的アプローチ（高精度）では、全フィルターオン、ADX閾値25〜30、レジーム閾値-0.1から0.1を使用する。攻撃的アプローチ（より多くのシグナル）では、ボラティリティフィルターのみ、閾値を下げ、選択的なEMA/SMAフィルターを使用する。

時間軸選択として、スキャルピング（15分〜1時間）では全フィルター有効化とアクティブモニタリング、スイング（4時間〜日足）では最適でデフォルト設定が良好に機能、ポジション（日足〜週足）では非常にクリーンなシグナルで最小限の調整となる。

### リスク管理の実装

ポジションサイジング公式は、ポジションサイズ = （口座 × リスク%）/ ストップロス距離となる。例：（10,000ドル × 2.5%）/ 100ドル = 2.5契約。

イグジット戦略として、保守的は固定4バー保有、中程度は反対シグナルでイグジット、攻撃的は動的カーネルベースのイグジット、最適はレイヤード（ブレークイーブン、部分、トレーリング）となる。

## 重要な注意事項とベストプラクティス

### リペイントに関する確認事項

バークローズ後のリペイントなし（確認済み）、MLの予測とカーネル推定の両方がリペイントしない、バー形成中の更新は正常（バーがクローズするまで）という点が重要である。

### DO（すべきこと）とDON'T（すべきでないこと）

すべきこととして、トレンドフィルター（EMA、SMA）を使用、ボラティリティ/レジームフィルターを有効化、現実的な手数料でバックテスト、適切なポジションサイジングを適用（最大2〜3%）、ドローダウン中も我慢強く、デフォルトから開始し段階的に最適化する。

すべきでないこととして、全てのシグナルを盲目的にトレード、限られたデータで過剰最適化、市場レジームを無視、トレード当たり3%以上のリスク、上位時間軸トレンドに逆らうトレード、全ての状況で一貫性を期待するといった点が挙げられる。

## 結論：成功への統合的アプローチ

Lorentzian Classificationは、物理学に触発された洗練されたアプローチを取引に適用し、イベント駆動のボラティリティ、外れ値への感受性、価格-時間のワープという課題に対処する。成功的な実装には、**複数の確認を要求する統合的アプローチ**が不可欠である。

最高確率の組み合わせは、スイングトレードではLorentzian + 200EMA + Supertrend（日足チャート）、デイトレードではLorentzian + MACD + RSI（15分足チャート）、出来高ベースではLorentzian + VWAP + OBV（4時間/日足）となる。

重要な成功要因として、スタイルに合った適切な時間軸選択、高出来高セッション中のみのトレード、複数指標の確認、厳格なリスク管理、高品質セットアップへの忍耐が挙げられる。初心者は日足チャートのスイングトレードから開始し、Lorentzian + 200EMA + Supertrendを使用し、ライブ前に最低2〜3ヶ月のペーパートレード、リスク管理をマスターしてから複雑性を追加すべきである。
